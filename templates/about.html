What RSP Does

Review Sentinel Prime extends the original Replication Package Builder with a full browser-based interface and automation features:

Boolean search across 12 databases
Boolean query syntax with in-page tips
Live search progress & elapsed timer
Save & schedule recurring searches
Email notifications with diff comparison
Title & Abstract screening (T&A)
AI screening assistant (local LLM, human-in-the-loop)
Interactive charts (year, keywords, venue, type)
PRISMA 2020 flow diagram & evidence checklist
Review Protocol form (auto-completes PRISMA items)
Clickable stage & excluded-paper cards
Snowballing / other sources integration
PNG export (flow diagram & checklist)
Cards & List view toggle
CSV & replication package ZIP export
New / removed paper diff between runs
Include / Exclude terms & venues (ANY/ALL)
Export / Import full search config (JSON)
API key management & SMTP config
Built-in user manual
Validation papers (completeness check)
Live / Offline filter mode (cached re-filtering)
Results Hub — browse & download run snapshots
Docker one-click deployment

Origins

Review Sentinel Prime (RSP) builds upon the work of the Replication Package Builder, a tool designed to compile scientific publications from multiple academic databases (IEEE Xplore, ACM Digital Library, Scopus, ScienceDirect, HAL Open Science, Springer Nature, Inspec, PubMed, arXiv, and more) to support Systematic Literature Reviews and Mappings.

The original tool was used to produce the Replication Package for a Systematic Literature Mapping of Agility in Safety-Critical Software Development within the Aerospace Industry (DOI: 10.5281/zenodo.13763171).

RSP (2026) extends this vision with a lightweight, locally-run web interface that allows researchers — regardless of coding experience — to search databases, schedule automated runs, and manage results entirely in the browser.

Tech Stack

RSP runs entirely on your local machine — no cloud account required. The only outbound connections are the literature database APIs, the optional SMTP server for email notifications, and the response forms used by the Feedback and Survey pages.

Python 3.12 Flask 3.1 APScheduler 3.10 Jinja2 Chart.js 4.4 html2canvas 1.4.1 Local JSON storage smtplib (email) Inter (Google Fonts) requests 2.32 Docker & Compose Ollama / OpenAI-compatible LLM (optional)
